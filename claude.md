# Проект библиотека

## Стэк технологий
- .NET Core 9 Web API
- ORM (Postgres) in Docker

## Project
Проект для тестов, но основная идея — хранение, выдача книг и продажа их.

## Basic rules

### Файлы и структура
- Все файлы создаются внутри проекта.
- Исключение: конфигурационные файлы, требующие размещения вне корня проекта (например, CI/CD, IDE-настройки) — такие случаи оговаривать с пользователем перед созданием.
- Справочные файлы (ADR, схемы БД, диаграммы, описания решений) создаются в папке `docs`.
- README и техническая документация к конкретному модулю — рядом с кодом этого модуля, а не в `docs`.

### Архитектура
- Архитектура базируется на принципах "Чистой архитектуры" со следующим разделением слоёв: `Domain / Application / Infrastructure / Api`.
- Актуальная структура папок и правила зависимостей между слоями зафиксированы в `docs/architecture.md`. При любых сомнениях — сверяться с этим файлом, а не трактовать "Чистую архитектуру" произвольно.

### Внешние источники
- Запрещено использовать код или файлы вне текущего проекта, находящиеся на локальной машине (другие репозитории, файлы на рабочем столе и т.д.).
- Исключение: если пользователь явно и прямо разрешил обратиться к конкретному внешнему источнику в своём сообщении.
- Если такого явного разрешения нет — использование внешних источников запрещено по умолчанию.
- Если разрешение получено — официальная документация используется как основной источник. Сторонние блоги, форумы и неофициальные примеры допустимы только если официальной документации недостаточно для решения задачи.
